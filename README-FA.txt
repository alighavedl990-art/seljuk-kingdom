بازی سلجوقیان - نسخه اولیه

۱) همه فایل‌ها و پوشه‌های این بسته را در ریشه مخزن GitHub قرار بده.
۲) در Netlify گزینه Add new site > Import an existing project را انتخاب و مخزن seljuk-kingdom را وصل کن.
۳) در Site configuration > Environment variables متغیر KING_KEY را با یک رمز دلخواه و قوی بساز.
۴) سایت را Deploy کن.

نکته: کلید KING_KEY را در پیام یا مخزن عمومی منتشر نکن. لایک عمومی است و هر بار ۵ غذا اضافه می‌کند؛ فرمان‌های مدیریتی به کلید پادشاه نیاز دارند.
