# پادشاهی سلجوقیان

نسخه‌ی قابل‌بازی مرورگری با رابط فارسی و نقشه‌ی ایزومتریک. بدون نصب وابستگی اجرا می‌شود.

## اجرا
- فایل `index.html` را در مرورگر باز کنید؛ یا پوشه را با یک وب‌سرور استاتیک سرو کنید.
- برای Netlify، کل پوشه را منتشر کنید. Build command خالی و Publish directory برابر `.` است.

## امکانات
- نقشه ایزومتریک ۱۳×۱۳ با قصر مرکزی، خیابان‌های متقاطع و فضای قابل ساخت
- ساخت خانه، مزرعه، معدن طلا، بازار، انبار و پادگان
- تولید خودکار غذا و طلا با نیروی کار شهروندان
- منابع غذا، طلا، جمعیت، سرباز و امنیت
- مالیات، سربازگیری، تقویت دفاع و تجارت
- گذر زمان، مصرف غذا و رشد تدریجی جمعیت
- ذخیره خودکار روی مرورگر همان دستگاه با localStorage

## محدودیت نسخه فعلی
این نسخه تک‌دستگاهی است؛ ورود چند بازیکن هم‌زمان، حساب کاربری، همگام‌سازی ابری و اقتصاد آنلاین در آن وجود ندارد. داده‌ها با پاک‌کردن داده‌های مرورگر یا استفاده از دستگاه دیگر منتقل نمی‌شوند.

## انتشار
برای Netlify، مخزن را متصل کنید، Build command را خالی و Publish directory را `.` قرار دهید.
