# پادشاهی سلجوقیان

نسخهٔ مرورگری فارسی با نقشهٔ ایزومتریک ۱۳×۱۳؛ بدون وابستگی یا فرایند build اجرا می‌شود.

## اجرا
1. فایل‌ها را دریافت کنید.
2. `index.html` را در مرورگر باز کنید یا پوشه را به‌عنوان سایت استاتیک منتشر کنید.
3. برای Netlify مقدار Publish directory را `.` و Build command را خالی بگذارید.

## امکانات
- قصر مرکزی، خیابان‌های متقاطع و خانه‌های قابل ساخت
- خانه (هر خانه ۱۰ نفر ظرفیت)، مزرعه، معدن طلا، بازار، انبار و پادگان
- تولید غذا و طلا، جمعیت، سرباز و امنیت
- اخذ مالیات، سربازگیری، تقویت دفاع و دادوستد
- هر بار فشردن دکمهٔ حمایت مردمی: ۵ واحد غذا
- ذخیرهٔ خودکار در حافظهٔ مرورگر همان دستگاه

## نکته
پیشرفت بازی با localStorage روی همان مرورگر/دستگاه نگهداری می‌شود و فعلاً همگام‌سازی ابری یا چندنفره ندارد.
