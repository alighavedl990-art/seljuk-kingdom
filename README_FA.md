# پادشاهی سلجوقیان

نسخهٔ فارسی بازی شهرسازی با نقشهٔ ایزومتریک ۱۳×۱۳.

## اجرای بازی
فایل `index.html` را در مرورگر باز کنید. برای انتشار در Netlify، پوشهٔ اصلی را منتشر کنید؛ Build command خالی و Publish directory برابر `.` باشد.

## امکانات
- قصر مرکزی و خیابان‌های منظم
- ساخت خانه (ظرفیت هر خانه ۱۰ نفر)، مزرعه، معدن طلا، بازار، انبار و پادگان
- تولید خودکار غذا و طلا
- منابع جمعیت، سرباز و امنیت
- مالیات، سربازگیری، دفاع و تجارت
- هر لایک: ۵ واحد غذا
- ذخیرهٔ خودکار روی همان دستگاه با localStorage

ذخیرهٔ بازی فعلاً محلی است و بین دستگاه‌ها همگام نمی‌شود.
